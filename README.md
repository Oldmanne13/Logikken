# LogikLab

En enkel, statisk undervisningsapp til logiske gates, målrettet cirka 8. klasse.

## Indhold

- **Lær:** AND, OR, NOT og XOR én gate ad gangen med korrekt symbol, klikbare inputs og sandhedstabel.
- **Øv:** små opgaver med én gate ad gangen.
- **Udfordring:** trinvis analyse af det faste kredsløb `OUT = (A AND C) AND NOT(B OR D)`.
- **Læringsassistent:** regelbaserede hints, spørgsmål og eksempler på gode AI-spørgsmål. Den giver ikke automatisk facit.
- **Ekstra:** en enkel Minecraft/redstone-analogi for AND samt eksempler på, hvordan AI kan bruges til læring.

## GitHub Pages

Læg `index.html`, `style.css` og `script.js` i roden af et GitHub-repository.

Aktivér derefter:

1. **Settings**
2. **Pages**
3. **Build and deployment → Deploy from a branch**
4. Vælg `main` og `/ (root)`

Der er ingen backend, database eller API-nøgle i denne version.
